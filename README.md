# Missale Romanum — Vetus Ordo

Spazio pubblico dell'app Android **Missale Romanum** (Messale Romano 1962, in latino e italiano).

Qui si trovano:

- `messe_presenza.json` — luoghi in Italia dove si celebra la Santa Messa in rito antico (orari da verificare prima di andare);
- `messe_diretta.json` — canali con Sante Messe trasmesse in diretta;
- le versioni dell'app da scaricare (sezione *Releases*, in preparazione).

L'app scarica questi elenchi quando c'è connessione, così possono essere aggiornati senza pubblicare una nuova versione.

**Segnalazioni e correzioni** (luoghi nuovi, orari cambiati, Messe soppresse): info@dellapittima.it

Fonte iniziale dell'elenco dei luoghi: elenchi regionali di [Messainlatino.it](https://blog.messainlatino.it/elenco-messe-antiche-in-italia).
